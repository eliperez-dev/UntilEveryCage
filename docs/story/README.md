# Aggregate story evidence

The [claim ledger](claim-ledger.md) retains statistical source and calculation
references. [Aggregate-statistics rules](../statistics/aggregate-statistics-spec.md)
own units and denominators. Narrative/story experiments are deferred ideas in
[the product roadmap](../PRODUCT-READINESS.md), not launch instructions here.

The retained [FAOSTAT catalog](../../data/manifests/animal-scale-statistics-catalog.json)
covers sixteen 2024 World meat items, 87,892,277,479 animals and a 366-day model.
The 2026-10-24 check reproduced arithmetic; the named raw archive was unavailable,
so that check did not reverify upstream extraction or its recorded checksum.
This selected statistical catalog is not the implemented 18-group V1-derived
About counter. Do not substitute one for the other or reintroduce removed
counter disclosures; the [frontend guide](../frontend/README.md) owns that UI.
